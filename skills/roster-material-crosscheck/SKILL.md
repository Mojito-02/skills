# 名单 × 申报材料 交叉核对

## 适用场景

一份名单表（xls/xlsx，一人一行，含学号/姓名/应报类别）+ 一个按班级/单位分子目录的材料目录（每份材料一个 PDF）。
要回答的问题：**谁没交、谁交的类别/层级不对、哪些文件名不能用**。

## 铁律（先跟用户确认，不要自己定）

1. **判定依据**：是只看**文件名**，还是要读 PDF 正文？
   - 只看文件名：快、稳、无依赖，但只能判"层级/编号"这类从文件名可读的信息。
   - 读正文：能判细类别，但 PDF 常有陷阱——康熙部首（⼈/⽣/⼲）、无文字层的扫描件、标签被排版拆行（`本人申报类` / `值` / `别`）。
   - **务必让用户先拍板**，两种口径结论数量差很多。
2. **命名规范**：通常形如 `(校|院)<学号><姓名>.pdf`，前缀即层级。先向用户确认规范，再写正则。
3. **匹配粒度**：一般"只对账，不相加"，不多不少一人一份。

## 步骤

1. **读名单**：`.xls` 是老 OLE2 格式，用 `xlrd`（2.x 只支持 xls，正好）。取 学号/班级/姓名/类别 列，类别列非空者才是应报人群。
2. **扫材料目录**：`os.walk` 收集全部 PDF 文件名，正则拆出 `(前缀, 学号, 姓名)`。
3. **两遍匹配**（关键，漏一遍就会误报缺交）：
   - 第一遍：`学号后7位 + 姓名 交集优先` → 唯一则命中；否则 `姓名唯一` 兜底；否则 `学号唯一` 兜底。
   - 第二遍：**对第一遍没匹配上的文件**，按姓名单独认领，结论记「文件名待规范」——材料其实交了，只是名字不合规，**不能算缺交**。
4. **出结论**：`齐 / 缺交 / 级别不符 / 文件名待规范`。每条问题都写清"差什么、怎么改"（如"建议改名为 院2222408029肖文熠.pdf"）。
5. **Excel 交付**：`核对总表`（全量逐人，一行一人，含结论）+ `问题清单`（只列非齐，按班级/学号排序，可直接发群催收）。
6. **反复重跑**：学生是陆续交的。把脚本做成**幂等原地刷新**——只回填结论相关列，重建问题清单，保留用户改过的版式。

## 踩坑清单

- **学号重号**：不同人可能后7位相同（如 `2508002` 同时对应 S2508002 和 Z2508002），且有人会在文件名里**抄错学号**。所以 `学号+姓名交集 → 姓名兜底`，别只认学号。
- **文件名缺前缀 / 多后缀**：`2222408029肖文熠.pdf`（缺校/院）、`黄秋景..pdf`（双点）、`徐慧(1).pdf`（重复下载）。单独列「文件名待规范」，不要归入缺交。
- **扫描件**：`page.get_text()` 为空但有图片 → 只能人工看，标注出来。
- **文件名里的中文**：命令行 `-c` 里硬编码中文路径偶发编码问题；可靠做法是 Write 脚本文件再执行。
- **刷新既有 xlsx 的配色**：别硬编码颜色。从**同一张表里已有的对应状态行**复制 `fill`/`font`（`copy()`），能自动继承用户改过的主题。
- **`load_workbook` → 自底向上 `delete_rows` → 另存**：这是"过滤行但保住格式"的最省事写法，单元格样式会随行上移。
- **freeze_panes 会被 WPS/Excel 悄悄改**成当前滚动位置（如 A26、A38）。刷完统一设回 `A2`。
- **`.workbuddy\backup\` 先备份**：每次覆盖用户的表之前，`Copy-Item` 一份带时间戳的副本。
